# Code of conduct

## Our standard

Treat people with respect. Discuss the work, ask clear questions, and accept correction without hostility.

Good participation includes:

- giving useful feedback on code and ideas;
- making room for people with different experience levels;
- owning mistakes and repairing harm;
- respecting privacy and personal boundaries.

Unacceptable behavior includes harassment, discrimination, threats, sexual attention, insults, doxxing, and sustained disruption.

## Scope

This code applies in repository discussions, issues, pull requests, reviews, and project events. It also applies when someone represents the project in public.

## Reporting

Report conduct concerns privately to the repository maintainers. Do not open a public issue that names the people involved.

Maintainers will review reports promptly, protect private details where possible, and act based on the behavior and its impact. Responses may include a correction, warning, temporary restriction, or permanent ban.

Maintainers must step away from any report where they have a conflict of interest.
